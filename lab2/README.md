# Лабораторная работа №2 — Основы ООП и принципы проектирования

Реализация иерархии классов на Python, демонстрирующая четыре столпа ООП
(инкапсуляция, наследование, полиморфизм, абстракция) и принципы SOLID.

## Язык и инструменты

- Python 3.13
- Visual Studio Code

## Структура проекта

```
lab2/
├── pet.py        # интерфейс (абстрактный класс) Pet
├── animal.py     # абстрактный класс Animal
├── turtle.py     # класс Turtle
├── parrot.py     # класс Parrot
├── person.py     # класс Person
├── main.py       # точка входа
└── README.md
```

## Иерархия классов

```
        Pet (ABC)
         ▲
         │
      Animal (ABC)
       ▲     ▲
       │     │
   Turtle   Parrot
```

- `Pet` — абстрактный контракт: `express()`, `get_name()`, `get_age()`, `get_age_in_human_years()`
- `Animal` — общее состояние (имя, возраст) и `happy_birthday()`
- `Turtle`, `Parrot` — переопределяют `express()` и `get_age_in_human_years()`
- `Person` — хранит питомца типа `Pet`, метод `get_pet_info()` выводит информацию

## Формулы возраста в человеческих годах

- **Parrot:** `age * 5`
- **Turtle:** первый год = 15, каждый следующий = 2 → `15 + (age - 1) * 2`

## Как запустить

```bash
python main.py
```

## Применённые принципы ООП

| Принцип | Где проявляется |
|---|---|
| Инкапсуляция | Поля `_name`, `_age`, `_pet` приватные |
| Наследование | `Turtle` и `Parrot` наследуют `Animal`, который наследует `Pet` |
| Полиморфизм | `Person` работает с `Pet`, поведение берётся из `Turtle`/`Parrot` |
| Абстракция | `Pet` и `Animal` — абстрактные |

## Принципы SOLID

- **SRP:** каждый класс меняется по одной причине
- **OCP:** добавить `Cat` — просто новый класс, `Person` не меняется
- **LSP:** `Parrot` и `Turtle` подставляются вместо `Pet`
- **ISP:** интерфейс `Pet` узкий
- **DIP:** `Person` зависит от `Pet` (абстракция), а не от конкретных классов
