# Лабораторная работа №3 — Порождающие паттерны проектирования

Реализация текстовой RPG-игры (упрощенная версия) с использованием пяти порождающих паттернов проектирования на Python.

## Структура проекта

- `dice.py` — паттерн **Одиночка (Singleton)**. Игральная кость, единая для всей игры.
- `items.py` — паттерн **Прототип (Prototype)**. Предметы умеют создавать свои глубокие копии.
- `abstract_factory.py` — паттерн **Абстрактная фабрика (Abstract Factory)**. Создает семейства предметов (оружие + броня) для разных классов героев.
- `builder.py` — паттерн **Строитель (Builder)**. Пошаговое создание героя с проверкой обязательных полей.
- `factory_method.py` — паттерн **Фабричный метод (Factory Method)**. Локации создают разных врагов, не привязываясь к их конкретным классам.
- `main.py` — демонстрация работы всех паттернов с выводом в консоль.

## Как запустить

Из папки `lab3`:

```bash
python main.py
